# 像素马里奥 · maliao

**Canvas 2D 平台跳跃游戏** —— 像素风格的马里奥式平台跳跃实现，纯前端单文件运行。

**[在线试玩](https://tuanzi188.github.io/maliao/)** · [玩法说明](玩法说明.html)

## 玩法特性

- 经典平台跳跃：移动、跳跃、踩敌人、顶砖块
- **无敌星系统**：星星砖 109 出星、弹跳拾取、9 秒白身闪烁 + 碰敌杀敌 + BGM 加速
- **300 秒倒计时**：HUD 红闪提示、归零死亡、时间加成
- 角色建模修正：帽徽 M、乌龟侧视等细节打磨
- 关卡与敌人：地面、管道、砖块、敌人巡逻与地形布局

## 快速开始

直接用浏览器打开 `index.html` 即可游玩。

完整的玩法与操作说明见 [玩法说明.html](玩法说明.html)。

## 项目结构

```text
index.html            游戏主体（单文件）
玩法说明.html          玩法与操作说明
tools/                开发期辅助脚本（精灵素材生成/替换/调试，非游戏运行时依赖）
sprites_raw/          精灵素材源文件
```

## 说明

`tools/` 下的脚本为开发期一次性工具（精灵生成、素材替换、音效调试等），游戏运行不依赖它们。
